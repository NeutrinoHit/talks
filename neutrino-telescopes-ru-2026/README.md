# Нейтринные телескопы (лекция для студентов, русская версия)

Д. В. Наумов. Русский язык. Аудитория: студенты без подготовки в физике нейтрино.
Сокращённая и упрощённая версия лекции `../neutrino-telescopes-2026` (английский оригинал).

## Структура

`lecture.qmd` собирает блоки:

| блок | содержание |
|---|---|
| `_01-opening.qmd` | премия и переписка, «И что?» (1 ПэВ), фильм Bert, Ernie и Big Bird; что такое нейтрино |
| `_02-history.qmd` | Марков, DUMAND (1979 и 1993), Байкал, путь к кубическому километру |
| `_03-principles.qmd` | как поймать нейтрино, черенковский свет, фотоумножитель, треки и каскады |
| `_04-sources.qmd` | космические ускорители, как джет рождает нейтрино |
| `_05-results.qmd` | поток из космоса, Млечный Путь, первые источники, KM3-230213A |
| `_06-future.qmd` | как увидеть больше, телескопы мира, вопросы, итоги, люди |
| `_09-appendix.qmd` | приложения: формулы и технические слайды из английской лекции |

Каждый блок начинается с титульного слайда. В основной части 21 содержательный слайд,
формулы почти только в приложениях, тексты — списками. Заметок докладчика нет.

## Нерпа

Персонаж-питомец для разрядки: `media/nerpa/nerpa.js` (копия сборки `dvnanima/nerpa/web/nerpa.js`;
исходник персонажа и трюков — `dvnanima/nerpa`, после правок там пересобрать `build_web.py` и скопировать файл).
Подключён в `_metadata.yml`. На слайде нерпу задаёт `<div data-nerpa="…">` в `{=html}`-блоке;
позиция — относительно всего слайда. Три места, не больше:

| слайд | момент | трюк |
|---|---|---|
| «Байкал: лёд как платформа», вкладка «Романтика» | после истории DUMAND | по клику выглядывает справа снизу, машет ластом, ныряет (`peek`, `data-gesture="wave"`) |
| «Черенковский свет», вкладка «Почему конус?» | после единственной формулы | по клику проплывает понизу с клином волн за кормой, как катер (`dash`) |
| титул раздела «Что мы уже знаем» | после самого трудного слайда (предел Ваксмана — Бакала) | дремлет внизу, из носа растёт и лопается пузырь (`nap`) |

Клавиша **Н** (латинская Y) отправляет нерпу через текущий слайд, **Shift+Н** — выглянуть из угла;
в PDF-версии нерпы нет. В скрытой вкладке нерпа не запускается: клик по фрагменту тогда ничего не показывает.
